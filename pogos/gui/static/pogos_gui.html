Run pogos_reset: deletes (and recreates

Every pogos_run (from this gui, a batch
job or a terminal) records where it is: the stage (pre-extraction /
extraction / post-extraction), the flavour (e.g. SOSSISSE) and the steps
inside it, as deep as the code marks them (e.g. per detector, per jump
chunk, per section). Steps the code declares up front show as
pending until they run. Click a run to see its steps; on each step
Log opens the log there, Code shows the code that runs it
and Doc what it does.
